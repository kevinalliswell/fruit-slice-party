# Code of Conduct

## Our Pledge

We pledge to make participation in this project a welcoming, respectful, and harassment-free experience for everyone, regardless of age, ability, background, identity, or level of experience.

## Expected Behavior

- Be respectful, patient, and constructive.
- Focus feedback on the work, not the person.
- Welcome questions and different levels of experience.
- Accept responsibility, apologize, and correct mistakes.

## Unacceptable Behavior

Harassment, discriminatory language, personal attacks, deliberate intimidation, publishing private information, or other conduct that would reasonably be considered inappropriate is not acceptable.

## Enforcement

Project maintainers may edit, remove, or reject contributions and may temporarily or permanently restrict participation when this code is violated. Reports should be sent privately through the maintainer's GitHub profile. Maintainers will respect the privacy and security of reporters.

This policy applies in all project spaces and when representing the project publicly.
