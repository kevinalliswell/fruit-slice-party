# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-12

### Added

- Nine fruit types with weighted appearances and distinct scores
- Easy, medium, and hard timed challenges
- Touch and mouse slicing with collision detection
- Canvas fruit artwork, slice particles, score bursts, and bomb explosions
- Pause, countdown, win, bomb failure, and timeout flows
- Generated Web Audio sound effects with mobile browser unlocking
- Responsive layouts for mobile, tablet, and desktop browsers
- Automated tests for rules, geometry, and audio behavior
