# Security Policy

## Supported Versions

Security fixes are applied to the latest version on `main`.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository:

https://github.com/kevinalliswell/fruit-slice-party/security/advisories/new

Include reproduction steps, affected browsers or versions, and the potential impact. You can expect an acknowledgement within seven days. Please allow time for a fix before publicly disclosing the issue.

The game does not collect user data, use authentication, or connect to external runtime services. Reports about dependency integrity, unsafe browser behavior, or repository automation are still welcome.
